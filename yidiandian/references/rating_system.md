# 目标距离评级体系 D~S++

## 评级标准

| 等级 | 含义 | 预估周期 | 说明 |
|------|------|----------|------|
| D | 基本已会，只需微调 | 1-3天 | 用户已具备几乎所有必要技能，仅需细节打磨 |
| D+ | 略需补充 | 3-7天 | 缺一两个小技巧或知识点，快速补齐即可 |
| C | 短期可成 | 1-2周 | 具备大部分前置能力，少量专项练习即可达成 |
| C+ | 需专项练习 | 1-3周 | 需要 1-3 项技能的针对性训练 |
| B | 中等距离 | 2-4周 | 需针对性训练几个核心模块 |
| B+ | 模块间有依赖 | 1-2月 | 技能模块存在先后顺序，需按序攻克 |
| A | 较远 | 3-6月 | 需要系统提升多个维度 |
| A+ | 涉及领域较广 | 6-12月 | 需分阶段完成，跨多个知识领域 |
| S | 极远 | 1年+ | 大师级目标（如职业级演奏家） |
| S+ | 需天赋+长期刻意练习 | 数年 | 即使方法正确也需极长时间投入 |
| S++ | 几乎不可能短期定义完成标准 | 不适用 | 如"成为行业顶尖"，无法定义清晰的完成标准 |

## 使用规则

1. 评级基于用户提供的 **current_level** 与 **goal** 之间的差距。
2. 评级理由必须是一句话，说清"差在哪里"。
3. 评级仅作为参考，不用于打击用户积极性——B 级及以下可以加上鼓励语（如"B级，一个月搞定，完全可行"）。
4. 若用户已有相关经验（从记忆中检索），可在评级中体现（如"考虑到你上次已经练过基础和弦，实际距离降到 C+"）。

## 示例

- 目标：用尤克里里弹《Toxic》 | 基础：只会简单指弹 → **B级**（需掌握特定和弦、节奏型、整曲整合，约1个月）
- 目标：用 Python 写一个爬虫 | 基础：会基本语法 → **C级**（补 requests + 解析库即可，1-2周）
- 目标：成为职业钢琴演奏家 | 基础：零基础 → **S级**（需按年计的系统训练）
