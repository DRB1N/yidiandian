# 资源评估标准

## 核心原则

每个推荐资源必须满足以下 6 项标准中的 **至少 2 项**，并在推荐时明确说明满足哪些标准。

## 六项评估标准

### 1. 内容匹配度
资源是否直接针对当前技能点。
- 高分：教程标题/内容与技能点高度吻合
- 低分：泛泛而谈的入门课，未覆盖具体技能点

### 2. 讲解清晰度
步骤是否分明、是否有示范。
- 高分：有分步演示、慢速回放、关键点标注
- 低分：只有文字描述或一镜到底无重点

### 3. 难度适配
与用户当前基础是否匹配。
- 高分：从用户当前水平起步，逐步进阶
- 低分：过于基础（浪费时间）或过于高级（看不懂）

### 4. 用户评价
播放量、点赞、收藏、评论反馈。
- 高分：高播放量 + 正面评论 + 高收藏率
- 低分：低播放量或有负面反馈

### 5. 时效性
发布时间是否新鲜。
- 技术类：1 年内为佳，2 年内可接受
- 人文技能类：2 年内为佳，经典内容不限
- 超过时效的资源需标注"内容较老但方法仍适用"

### 6. 完整性
是否包含慢速演示、纠错、谱例/代码等辅助材料。
- 高分：有配套谱例、代码仓库、纠错指南
- 低分：只有单一视频/文章，无辅助材料

## 推荐格式

```
资源：《[标题]》 | 创作者：[...] | 平台：[...] | 链接：[...]
选择理由：满足标准[1,3,6] — 内容直接针对[技能点]，步骤清晰有慢速演示，配有谱例下载
```

## 注意事项

- 禁止推荐无法验证来源的资源。
- 禁止编造播放量、评价数据。
- 若搜索结果有限，诚实说明"这个领域公开资源不多，以下是我找到的最好的"。
- 付费资源需标注"付费"，并提醒用户自行评估性价比。
